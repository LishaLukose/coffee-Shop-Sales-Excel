# coffee-Shop-Sales

This repository contains a data analysis and dashboard visualization of a coffee shop's sales using Microsoft Excel. The dashboard provides actionable insights into customer behavior, sales performance, and product trends.

## Project Objective

To analyze coffee shop sales data and create an interactive Excel dashboard that provides meaningful insights into customer behavior, product performance, and business trends. The goal is to support data-driven decision-making for improving sales strategies, inventory planning, and customer engagement.

## Dataset

- `Coffee Shop Sales.xlsx`

## Tools & Technologies

- **Data Visualization:** Excel     
- **Data Source:** Excel (.xlsx) 
- **Dashboard Development:** Microsoft Excel

## Key Features
 
 - Interactive Dashboard: Slicers and pivot charts for dynamic filtering by day, month, and location.
- Sales Summary: High-level KPIs including total sales, total orders, footfall, and averages.
- Time-Based Trends: Hourly order distribution to identify peak business hours.
- Category & Size Distribution: Visual breakdowns of sales by product category and order size.
- Location Analysis: Footfall and revenue by store location.
- Top Products: Ranking of the top 5 products based on sales revenue.
- Weekday Performance: Order trends segmented by day of the week.

## Key Takeaways

- Top Product: Barista Espresso generated the highest revenue (~$91K).
- Peak Hours: Most orders occur between 8 AM to 11 AM, highlighting busy breakfast hours.
- Best Performing Location: Hell’s Kitchen leads in sales (~$236K).
- Busiest Day: Friday has the highest number of orders.
- Order Size: Regular and Small sizes are equally popular, each with ~30% share.
- Customer Behavior: Average of 1.44 orders per person and ~$4.69 spent per visit.
